Plugin que integra conexión de minecraft a discord mediante Webhooks

Dependencia opcional: ViaVersion

Al instarlarlo e iniciar el servidor, se creara una carpeta con el nombre del plugin, dentro de la carpeta esta el archivo config.yml donde se puede activar/desactivar el envío de mensajes a discord,
colocar la url del webhook, y modificar el mensaje que se envía.

las variables disponibles son:
{player}
{uuid}
{version}
{time}

Dentro del servidor esta disponible el comando /joinlog reload
